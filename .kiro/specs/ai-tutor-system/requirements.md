# AI Tutor System - Requirements

## Overview
Context-Aware AI 튜터 시스템으로, 사용자의 현재 상황(미션 정보, 파드 로그, 힌트 이력)을 실시간으로 파악하여 소크라테스식 문답법으로 학습을 유도하는 지능형 에이전트입니다.

## User Stories

### 1. Context Collection (상황 인지)
**As a** 학습자  
**I want** AI가 내 현재 상황을 자동으로 파악하기를  
**So that** 내 상황에 맞는 맞춤형 힌트를 받을 수 있다

**Acceptance Criteria:**
- 1.1 사용자가 질문을 입력하면 시스템은 현재 미션 정보를 수집한다
- 1.2 시스템은 kubectl logs를 통해 실시간 파드 로그를 수집한다
- 1.3 시스템은 사용자의 과거 힌트 요청 이력을 조회한다
- 1.4 수집된 컨텍스트는 구조화된 형태로 AI 엔진에 전달된다
- 1.5 컨텍스트 수집은 3초 이내에 완료되어야 한다

### 2. Socratic Tutoring (소크라테스식 코칭)
**As a** 학습자  
**I want** AI가 정답을 바로 주지 않고 질문을 통해 유도하기를  
**So that** 스스로 문제를 해결하는 능력을 기를 수 있다

**Acceptance Criteria:**
- 2.1 AI는 직접적인 정답 대신 유도 질문을 제공한다
- 2.2 사용자의 이해도에 따라 힌트 레벨을 조정한다 (Level 1: 관찰 유도, Level 2: 개념 설명, Level 3: 완전한 해결책)
- 2.3 AI 응답에는 "왜 그런지" 사고하게 하는 질문이 포함된다
- 2.4 사용자가 3회 이상 막히면 자동으로 힌트 레벨을 상향한다
- 2.5 AI 응답 생성 시간은 5초 이내여야 한다

### 3. RAG-based Knowledge Retrieval (검색 증강 생성)
**As a** 학습자  
**I want** AI가 공식 문서 기반의 정확한 정보를 제공하기를  
**So that** 잘못된 정보로 학습하는 것을 방지할 수 있다

**Acceptance Criteria:**
- 3.1 Vector DB에 K8s 공식 문서와 트러블슈팅 매뉴얼이 저장되어 있다
- 3.2 사용자 질문과 관련된 문서를 벡터 유사도 기반으로 검색한다
- 3.3 검색된 문서의 관련도가 0.7 이상일 때만 응답에 포함한다
- 3.4 AI 응답에 참조한 문서의 출처를 명시한다
- 3.5 문서 검색은 2초 이내에 완료되어야 한다

### 4. Hint Level Management (힌트 단계 관리)
**As a** 학습자  
**I want** 필요에 따라 더 구체적인 힌트를 요청할 수 있기를  
**So that** 너무 오래 막혀있지 않고 학습을 진행할 수 있다

**Acceptance Criteria:**
- 4.1 힌트는 3단계로 구분된다 (Level 1: 관찰 유도 → Level 2: 개념 설명 → Level 3: 완전한 해결책)
- 4.2 사용자는 "더 자세한 힌트" 버튼으로 다음 단계를 요청할 수 있다
- 4.3 각 힌트 단계별로 점수 차감이 적용된다 (-5점, -10점, -50점)
- 4.4 힌트 요청 이력은 데이터베이스에 저장된다
- 4.5 동일 미션에서 이전 힌트 이력을 참조하여 중복 설명을 피한다

## Technical Requirements

### Performance
- AI 응답 생성: 5초 이내
- 컨텍스트 수집: 3초 이내
- Vector DB 검색: 2초 이내
- 동시 사용자 지원: 최소 50명

### Security
- API 키는 환경 변수로 관리
- 사용자 입력은 SQL Injection 방지 처리
- 로그에 민감 정보 노출 금지

### Scalability
- LLM API 호출 실패 시 재시도 로직 (최대 3회)
- Vector DB 인덱스 최적화로 검색 속도 유지
- 캐싱을 통한 중복 질문 처리 최적화
