# Dashboard & Gamification System - Requirements

## Overview
사용자의 학습 활동 데이터를 수치화하고 시각화하여 성장을 증명하며, 게이미피케이션 요소를 통해 학습 동기를 부여하는 대시보드 시스템입니다.

## User Stories

### 1. Real-time Scoring Display (실시간 점수 표시)
**As a** 학습자  
**I want** 미션 진행 중 실시간으로 점수 변화를 보기를  
**So that** 시간 압박감을 느끼며 집중력을 유지할 수 있다

**Acceptance Criteria:**
- 1.1 화면 상단에 현재 점수가 실시간으로 표시된다
- 1.2 1분마다 점수 차감 애니메이션이 표시된다 (-2점)
- 1.3 힌트 사용 시 즉시 점수 차감이 반영된다
- 1.4 미션 완료 시 최종 점수와 함께 축하 애니메이션이 표시된다
- 1.5 점수 변화 이력을 타임라인으로 확인할 수 있다

### 2. Skill Radar Chart (역량 레이더 차트)
**As a** 학습자  
**I want** 내 강점과 약점을 시각적으로 보기를  
**So that** 어떤 영역을 더 학습해야 할지 알 수 있다

**Acceptance Criteria:**
- 2.1 4대 핵심 역량을 육각형 레이더 차트로 표시한다 (트러블슈팅, 리소스 관리, 네트워크, 운영)
- 2.2 각 역량은 완료한 미션의 카테고리에 따라 점수가 누적된다
- 2.3 역량별 점수는 0-100 범위로 정규화된다
- 2.4 차트는 미션 완료 시 실시간으로 업데이트된다
- 2.5 각 역량을 클릭하면 관련 미션 목록을 보여준다

### 3. Learning Curve Graph (성장 곡선)
**As a** 학습자  
**I want** 시간이 지남에 따라 내 실력이 향상되는 것을 보기를  
**So that** 학습 효과를 실감하고 동기를 유지할 수 있다

**Acceptance Criteria:**
- 3.1 회차별 해결 시간을 꺾은선 그래프로 표시한다
- 3.2 회차별 힌트 사용량을 막대 그래프로 표시한다
- 3.3 동일 미션을 재도전한 경우 이전 기록과 비교한다
- 3.4 그래프에서 특정 지점을 클릭하면 해당 미션의 상세 정보를 보여준다
- 3.5 평균 해결 시간 대비 내 위치를 백분위로 표시한다

### 4. Tier System (티어 시스템)
**As a** 학습자  
**I want** 누적 점수에 따라 티어가 올라가기를  
**So that** 성취감을 느끼고 더 높은 목표를 향해 도전할 수 있다

**Acceptance Criteria:**
- 4.1 티어는 5단계로 구분된다 (Bronze, Silver, Gold, Platinum, DevOps Master)
- 4.2 각 티어는 누적 점수 기준으로 승급된다 (0-200, 201-500, 501-1000, 1001-2000, 2001+)
- 4.3 티어 승급 시 배지와 함께 축하 모달이 표시된다
- 4.4 프로필에 현재 티어 배지가 표시된다
- 4.5 티어별 전용 칭호가 부여된다

### 5. Leaderboard (리더보드)
**As a** 학습자  
**I want** 다른 학습자들과 순위를 비교하기를  
**So that** 경쟁심을 느끼며 더 열심히 학습할 수 있다

**Acceptance Criteria:**
- 5.1 전체 사용자의 누적 점수 순위를 표시한다 (Top 100)
- 5.2 미션별 최고 점수 순위를 표시한다
- 5.3 주간/월간 랭킹을 별도로 표시한다
- 5.4 내 순위와 상위 랭커와의 점수 차이를 표시한다
- 5.5 리더보드는 5분마다 자동으로 갱신된다

### 6. Achievement System (업적 시스템)
**As a** 학습자  
**I want** 특별한 조건을 달성하면 업적을 획득하기를  
**So that** 다양한 방식으로 도전하고 재미를 느낄 수 있다

**Acceptance Criteria:**
- 6.1 업적은 숨겨진 조건과 공개된 조건으로 구분된다
- 6.2 예시 업적: "완벽주의자" (힌트 없이 미션 완료), "스피드러너" (5분 이내 완료), "불굴의 의지" (10회 재도전 후 성공)
- 6.3 업적 달성 시 알림과 함께 프로필에 표시된다
- 6.4 업적별로 추가 점수 보너스가 부여된다
- 6.5 전체 업적 목록과 달성률을 확인할 수 있다

## Technical Requirements

### Data Collection
- 미션 시작/완료 시간 기록
- 힌트 요청 이력 저장
- 사용자 행동 로그 수집 (kubectl 명령어 실행 이력)
- 점수 변화 이력 저장

### Visualization
- Chart.js 또는 Recharts를 사용한 차트 렌더링
- 반응형 디자인으로 모바일 지원
- 실시간 데이터 업데이트 (WebSocket 또는 Polling)
- 애니메이션 효과로 사용자 경험 향상

### Performance
- 대시보드 로딩 시간: 2초 이내
- 차트 렌더링: 1초 이내
- 리더보드 갱신: 5분 주기
- 동시 접속자 지원: 최소 100명

### Database
- 사용자별 통계 데이터 저장
- 미션별 완료 기록 저장
- 리더보드 캐싱으로 조회 성능 최적화
- 일별 집계 데이터 생성 (배치 작업)
