# 프로젝트 제안서

## 프로젝트명
AfterFail

## 개요
클라우드 장애 대응 훈련을 위한 AI 기반 자동화 플랫폼

## 목표
- Chaos Engineering을 통한 실전 장애 시뮬레이션
- AI 기반 장애 분석 및 대응 가이드 제공
- FinOps 최적화 제안

## 기술 스택
- Frontend: React/Next.js
- Backend: FastAPI
- AI: LangChain, RAG
- Infrastructure: Kubernetes, Chaos Mesh
- Monitoring: Prometheus, Grafana, Loki
